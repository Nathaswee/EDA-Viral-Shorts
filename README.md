# EDA-Viral-Shorts
# Exploratory Data Analysis on Viral Shorts — Python Project

## Overview

Performed Exploratory Data Analysis (EDA) on 50,000+ viral shorts records to uncover audience engagement patterns and content performance insights using Python.

## Objectives

* Analyze engagement metrics of viral shorts
* Identify top-performing content categories
* Discover trends influencing video popularity
* Generate data-driven insights for content strategy

## Technologies Used

Python | Pandas | NumPy | Matplotlib | Seaborn | Jupyter Notebook

## Key Analysis Performed

* Data Cleaning and Preprocessing
* Univariate Analysis
* Bivariate Analysis
* Correlation Analysis
* Outlier Detection
* Visualization of engagement metrics

## Key Insights

* Identified content categories with highest engagement rates
* Found strong correlation between likes, shares, and views
* Detected posting trends impacting video reach
* Analyzed audience interaction behavior patterns

## Visualizations

* Count Plots
* Box Plots
* Histograms
* Correlation Heatmaps
* Bar Charts

## Files Included

* EDA_(viral_shorts)_PROJECT.ipynb

## Conclusion

The project successfully identified multiple engagement patterns and provided actionable insights that can help optimize short-form video content strategies.
